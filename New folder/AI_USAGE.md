# AI Usage Evidence

AI tools were used during the development of this project for guidance, debugging, code suggestions and understanding programming concepts.

## How AI Was Used

- Helped plan the structure of the Personal Expense Tracker.
- Provided guidance for HTML, CSS and JavaScript implementation.
- Helped debug errors and understand Git/GitHub commands.
- Suggested improvements such as the monthly budget feature.
- Helped explain how Local Storage works.

## Human Contribution

The project was tested manually, modified, and run in the browser. Features were checked by adding, editing and deleting expenses, using search and filters, and testing the monthly budget calculation.
